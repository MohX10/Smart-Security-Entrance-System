# Smart Security Entrance System

## Project Description 
A secure entry system that checks for card ID and password; To check if someone is allowed to enter the building or not.
Designed for protection against thugs or criminals to ensure people safety.

Key Features:
- It has two factor authentication (Card and Password)
- Alerts people if the card is wrong or password is wrong

Technologies: ESP32, MFRC522 RFID Module, 16x2 I2C LCD, HC-SR04 Ultrasonic Distance Sensor, Buzzer, 4x4 Matrix Keypad
